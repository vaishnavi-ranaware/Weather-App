#  Weather App

A simple and responsive Weather Application built using **HTML, CSS, and JavaScript**, integrated with the **OpenWeatherMap API**.  
This app allows users to search for any city and view real-time weather details like temperature, humidity, wind speed, and weather conditions.

##  Live Demo
https://vaishnavi-ranaware.github.io/Weather-App/

## ✨ Features
-  Search weather by city name  
-  Real-time temperature display (°C)  
-  Humidity percentage  
-  Wind speed (km/h)  
-  Dynamic weather icons (Clear, Clouds, Rain, Mist, Drizzle)  
-  Error handling for invalid city names  
-  Clean and responsive UI design  

##  Tech Stack
- HTML5  
- CSS3  
- JavaScript (ES6)  
- OpenWeatherMap API  

##  API Used
This project uses the **OpenWeatherMap API** to fetch real-time weather data.
